# AI-Powered Customer Churn Prediction & Behavior Mining

An AI-powered machine learning web application that predicts customer churn risk and analyzes customer behavior. The system helps businesses identify customers who are likely to leave and understand the possible reasons behind their churn.

## 📌 Project Overview

Customer churn is a major challenge for subscription-based businesses such as streaming platforms, telecom companies, banking services, and online applications.

This project uses Machine Learning and customer behavior analysis to:

- Predict whether a customer is likely to churn
- Classify customers into different risk categories
- Calculate churn probability
- Analyze customer behavior
- Identify possible reasons for customer churn
- Segment customers based on their behavior
- Provide data-driven insights for customer retention

---

## 🎯 Objectives

1. Predict customer churn using Machine Learning.
2. Identify high-risk customers before they leave.
3. Analyze customer activity and behavioral patterns.
4. Categorize customers based on their churn risk.
5. Help businesses take preventive retention actions.

---

## 🧠 Machine Learning

The project uses customer attributes and behavioral features to generate churn predictions.

### Main prediction outputs

- **High Risk** – Customer has a high probability of churning.
- **Medium Risk** – Customer shows moderate churn possibility.
- **No Risk** – Customer has a low probability of churning.

The system also provides the estimated churn probability for each customer.

---

## 🔍 Behavior Analysis

Customer behavior is analyzed using different features such as:

- Active Days
- Customer Activity
- Usage Patterns
- Subscription Information
- Customer Demographics
- Other available customer attributes

Behavioral segmentation is performed to identify different groups of customers.
